## §2 Mechanism: state augmentation (fork a)

**Decision: state augmentation.** Per-pass error coefficients c join the
coefficient state: z = [η; c], G_aug = [G B], Q_aug = diag(Q, Λ). The
observation model y = Gη + Bc + ε with white per-mission
ε ~ N(0, diag(σ²_m)) is exactly the structured-R model marginalized:

> **Marginalization identity (exact):** the field-block marginal of the
> augmented solve equals the solve under
> R_eff = diag(σ²_m) + B Λ Bᵀ.
> Executable form: the §5 extended duality oracle.

Solver untouched: `MiostSolver(g_aug, r_diag, q_diag_aug)` — columns +
diagonal entries only. The Jacobi preconditioner extends per-column by
construction (`miost_solver.py:47`: diag = Σ g²_ip/r_i + 1/q_p).

Cost arithmetic (re-derived, §12): ~+0.24% columns, ~+0.05% nnz per
window. The kickoff's conservative 5–10% guess is superseded by
arithmetic.

**Riders (owner ruling, verbatim intent):**

1. **State-block discipline** (the equivalence's fine print): the PRODUCT
   is the marginal over the FIELD block only — every query route (S-path
   grid, Γ-path points, member routes, down-conversion, variance) slices
   η; the c-block is solver-internal and contributes NOTHING to shipped
   fields. Tested by the §6 query-route pair. Window interplay stated: a
   pass in the overlap region gets independent per-window c estimates —
   legal (c never enters the product; blending acts on fields); recorded
   so nobody "fixes" it. The §8.5 adjacent-window ĉ agreement scatter
   turns it into free stability evidence.
2. **Sampling elegance recorded as the decisive mechanism argument**:

   machinery (c̃ ~ N(0, Λ) alongside η̃ ~ N(0, Q), white ε per-mission) —
   the §5 white-fed-structured-solve hazard is dissolved by construction,
   not guarded by care.
3. **Restriction semantics**: lane restrictions are STRUCTURAL COLUMN
   ABSENCE at zero mode variance — never an ε-variance or an infinite
   Λ⁻¹ diagonal. The §6 nesting identity runs against column-absent
   solves; a separate small-Λ continuity check (Λ→0 solution →
   no-column solution) guards the numerical seam. The continuity

## §3 Error basis: {bias, tilt} per pass, shared Λ (fork c)

**Box-chord physics (nearly settles the fork):** a pass chord through the
10° box is ~1100–1500 km; once-per-rev orbit/environmental error
(λ ≈ 40,000 km) sweeps ≈ 0.2 rad of phase across it — Taylor: constant +
tilt captures it to ~2% (the quadratic term).

**Basis, in s-units (defect corrected at review):** per pass, P0 = 1
(coefficient = bias, meters) and P1 = s (coefficient = chord-end tilt
amplitude, meters), s ∈ [−1, 1] the arc-length-normalized along-track
coordinate. NOT unit-normalized columns: unit-norm + shared Λ implies
physical prior variance ∝ 3Λ/n per pass — sampling-dependent physics,
rejected. Per-column conditioning is the Jacobi preconditioner's job (its
diagonal scaling IS per-column normalization, in the solver where it
belongs). Λ_tilt homogeneity caveat: ±15% chord-length spread ⇒ ±~30% in
implied slope variance — recorded, accepted at box scale.

**Normalization + segmentation pinned:** s spans the pass's
in-halo-domain obs extent; endpoints from THE pass segmentation (the
Phase-11 geometry artifact's — one segmentation, per §2 rider 5's cache
lineage). A pass in the window overlap gets IDENTICAL B columns in both
windows (spatial extent is window-independent). Short passes: no
special-casing — Λ regularizes (an isolated observation's
long-wavelength error is genuinely unconstrained; the mode correctly
down-weights it); the pass-length distribution is reported in the §8
diagnostic.

**Mode variances:** shared {Λ_bias, Λ_tilt} across missions (2 dims;
lane-C = 7). Boxes bracket PUBLISHED post-correction residual budgets
(the challenge L3 is corrected — §17; the target is residual orbit/LWE
structure, cm-order), log-space, generous both directions, sources
recorded (source table owed to the plan's pre-registration bundle).
Per-mission Λ (10 dims) is honest physics (orbit-determination quality
differs) but budget-blowing this phase — deferred to a
diagnostic-driven follow-on: the §8 variance-ratio trigger (cross-mission
contrasts) TABLES it for owner decision.

**Class-agnostic note:** every pass gets modes regardless of orbit_class
— the R structure is per-pass physics; the Phase-11 repeat/drifting
classifier is irrelevant here (pre-empting a likely confusion).

**P2 exclusion carries BOTH reasons:** Taylor-unsupported (~2% remainder
at ≈0.2 rad) AND absorption-risky (a ~700 km lobe resembles
large-mesoscale structure along the chord) — double rationale recorded so
a future revisit engages both.

1. **Variance-ratio table** per mission × mode: empirical var(ĉ)/Λ +

   CROSS-MISSION CONTRASTS (one mission departing from the common
   level), never absolute distance from 1. Doubles as the per-mission-Λ
   follow-on trigger (§3).
2. **Saturation fraction**: share of passes with |ĉ| > 2√Λ per mode;
   null < 5% with the same shrinkage note. Fires the §4 q_slope table
   trigger.
3. **Absorption discriminator**: lag-1 autocorrelation of the per-pass
   bias-coefficient sequence, per mission × FAMILY (asc/desc separated —

   wet-tropo) also autocorrelate; the flag is HIGH multi-day
   persistence, and row 4 breaks the ambiguity.
4. **Field-correlation complement**: corr(ĉ_bias,p, fitted-field
